# REQ04-Phase03 기술 사례 검증과 공개 준비

[로드맵의 Phase 상태](../../ROADMAP.md) · [요구사항](../../REQUIREMENTS/REQ04.md) · [콘텐츠 설계](../../SPEC/REQ04/content-architecture.md) · [선행 Phase](./Phase02.md)

## 선행 조건

REQ04-Phase02의 프로젝트 소개 연결, 세 글, 사용 이미지가 완성된 뒤 최종 확인을 시작한다. 자료 검증은 [프로젝트 지침](../../../AGENTS.md)을 따르고 [Phase01](../../REVIEW/REQ04/Phase01.md)과 [Phase02](../../REVIEW/REQ04/Phase02.md)의 확인 결과를 재사용한다.

## 검증 순서

1. 완성된 글에서 기존 확인 이후 바뀐 주장·코드·상태와 과장될 수 있는 표현만 확인한다. 현재 Nexon 명세를 단정하는 문장이 생긴 경우에만 공식 문서를 확인한다.
2. 공개 화면에서 자료 설명과 대체 설명이 읽히는지 살피고, 공개용 원본 파일에 실제로 가려야 할 정보가 있는지만 확인한다.
3. 기존 데스크톱·모바일 Playwright 결과를 재사용한다. 이후 수정한 링크·목차·이미지 표시·키보드 동작이 있으면 그 부분만 확인한다. 코드나 설정을 변경하면 프로젝트 지침에 따라 `pnpm check`와 `pnpm build`를 실행한다.
4. 확인한 변경과 남은 미확인 사항을 REVIEW에 기록한다. 공개 URL의 동작은 배포가 승인되어 반영된 뒤 확인한다.

## 산출물

수용 기준별 근거·검증 결과·남은 위험을 기록한 REVIEW와 공개 준비가 끝난 콘텐츠다. 배포, 커밋, 브랜치 정리는 별도 요청이 있을 때 수행한다.
