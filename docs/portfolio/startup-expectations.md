# 스타트업에 기대하는 점 입력용 초안

[작성 양식 이미지](../../screenshots/references/startup-expectations.png)의 항목에 맞춘 문안입니다. 지원할 회사와 역할에 맞게 선택과 표현을 조정하세요.

## 내가 기대하는 스타트업 — 최대 3개 선택

- 새로운 일에 도전
- 활발한 기술 논의
- 코드 리뷰

## 소개 문안

새로운 문제를 맡아 직접 구현하고, 그 과정에서 설계 이유와 검증 결과를 동료와 함께 논의할 수 있는 환경을 기대합니다. 저는 개발 규칙을 재사용 가능한 문서와 자동화로 정리하고, 데이터의 원본·검증·변경 단계를 구분하는 작업에 흥미가 있습니다. 이런 판단을 코드 리뷰와 기술 논의로 점검하며 더 나은 해결책을 찾고 싶습니다.

작은 팀에서는 각자가 맡은 기능을 구현하는 것만큼, 현재 가능한 범위와 남은 위험을 투명하게 공유하는 일이 중요하다고 생각합니다. 사용자에게 필요한 기능을 빠르게 실험하되, 서로의 피드백을 받아 안정적으로 발전시키는 팀에서 일하고 싶습니다.

## 공개 전 확인

- 선택한 기대 요소 3개가 실제 우선순위와 맞는지 확인
- 지원 회사의 제품·팀 문화에 맞춰 구체적인 이유 추가
- 직접 경험하지 않은 협업 방식이나 성과를 경험담처럼 표현하지 않았는지 확인
