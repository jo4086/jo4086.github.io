포트폴리오는 무엇을 만들었고 어떤 문제를 해결했는지 보여줍니다. 블로그는 개발뿐 아니라 기술 탐구와 일상 기록까지 꾸준히 쌓는 공간입니다. 두 영역은 같은 사이트에 있지만 읽는 목적이 다르므로 화면 구성도 구분했습니다.

## 화면의 역할

Home은 소개와 두 영역의 진입점만 남깁니다. Projects는 결과물과 기술적 맥락을 빠르게 훑을 수 있게 하고, Blog는 글을 찾고 읽는 데 집중합니다.

### 공통 구조

상단 내비게이션과 색상·타이포그래피는 공유합니다. 페이지별 본문 폭과 보조 탐색은 콘텐츠의 목적에 맞춰 달리합니다.

## 정적 사이트의 경로

GitHub Pages는 앱의 임의 경로를 서버에서 다시 `index.html`로 돌리는 설정을 제공하지 않습니다. 상세 페이지를 직접 열고 새로고침하는 흐름을 단순하게 만들기 위해 `HashRouter`를 선택했습니다.

## 데이터의 소유권

프로젝트 목록은 포트폴리오 기능이, Markdown 게시글은 블로그 기능이 관리합니다. 관련 글과 프로젝트는 slug로 연결하여 두 영역을 탐색할 수 있게 합니다.
